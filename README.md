# Think in SQL — DBMS Lab Companion

A mobile-first study note for the CSE353 Database Management System Lab: how to turn any
application-based question into a correct SQL query, plus five exam-style practice questions.

**Read it here:** https://siddharthharshraj.github.io/dbms-lab-query-mindset/

## What's inside

- **The first principle of a DBMS** — tables point at each other through keys, and a JOIN is just following that arrow.
- **The first principle of a query** — you translate English into a fixed grammar; Oracle runs `FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY`.
- **A six-move method** for reading a question with a highlighter and writing the query from the `FROM` clause outwards.
- **Joins decoded with pictures** — inner, left, right and full on the same tiny tables, plus the `COUNT(*)` trap and self joins.
- **Five practice questions** on a hospital schema, each with a "How to think" walkthrough. Answers are locked behind a passkey so you attempt them first.
- **Viva rapid-fire** one-line answers.

Every expected output in the answers was generated by running the queries against the real
dataset, not typed by hand.
